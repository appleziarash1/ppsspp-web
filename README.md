# PPSSPP Web — browser build

[PPSSPP](https://www.ppsspp.org/) (PlayStation Portable emulator) compiled to
WebAssembly, running entirely in the browser. Bring your own `.iso`, `.cso`,
`.chd`, or `.pbp`; the emulator reads the file locally and nothing is uploaded.

Live: **https://appleziarash1.github.io/ppsspp-web/**

This branch is generated by `scripts/publish-pages.sh` — edits here are
overwritten on the next publish. Source lives in
[appleziarash1/ppsspp-web](https://github.com/appleziarash1/ppsspp-web) (`main`).

## Controls

| Action | Keyboard |
| --- | --- |
| D-pad | Arrow keys |
| Cross / Circle / Square / Triangle | `Z` / `X` / `A` / `S` |
| L / R trigger | `Q` / `W` |
| Start / Select | `Space` / `Enter` |
| Analog stick | `I` `J` `K` `L` |
| Pause, fast forward, speed toggle | `Esc`, `Tab`, `` ` `` |

- **Mouse and touch** work through the emulator canvas.
- **Physical controllers** (USB or Bluetooth, SDL/XInput-compatible) are detected
  automatically. The header badge shows the active pad, and "Active controller"
  picks one when several are attached.
- **On-screen controller** appears on touch devices and hides itself the moment a
  physical controller connects. The header's pad toggle overrides either way and
  the choice is remembered across reloads.

## How this works on GitHub Pages

The Emscripten build is threaded and needs a cross-origin isolated page
(`SharedArrayBuffer`). GitHub Pages cannot send `Cross-Origin-Opener-Policy` or
`Cross-Origin-Embedder-Policy`, so `sw.js` adds those headers to every response
it serves. A service worker is therefore required for the emulator to start — the
page reports so in its status line if registration fails.
